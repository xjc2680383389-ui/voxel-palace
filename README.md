# 山河营造 · 体素中国古典建筑群

用 Three.js 构建的体素（Voxel）风格中国古典建筑群场景，中轴对称院落布局，浏览器打开即可观看。

## 场景内容

- **六座建筑，主次分明**：主殿「太和殿」居中轴核心、体量最大（重檐）；两侧对称配殿「崇文阁」「尚武阁」；前端入口山门「承天门」；另有两座对称钟鼓楼。
- **中式建筑形制**：实现庑殿顶、歇山顶（含木质山花）、攒尖顶；角部逐级抬升形成飞檐翘角；立柱含斗拱抽象；另台阶、栏杆、木格窗、灯笼、石狮、匾额（Canvas 贴图渲染真实殿名）。
- **空间动线**：山门 → 庭院 → 主殿 的连续中轴道路，两侧对称方池、石灯、松树。
- **环境光影**：方向光 + 2048 阴影贴图；「切换晨光/暮色」同步调整背景、雾、半球光与太阳色温。
- **视角控制**：拖动旋转、滚轮缩放、右键平移；工具栏提供「全景」「中轴」「环游」；快捷键 `R` 复位、`空格` 切换环游。首屏自动按场景包围盒取景，无需手动缩放。

## 技术要点

- 全场景 **13,171 个体素块**统一通过 `InstancedMesh` 一次性提交（按材质分桶，无逐方块 Mesh、无逐方块动画），实测量子帧率约 240 FPS。
- 确定性伪随机数（LCG）保证每次构建结果一致。
- 相机取景按屏幕包围盒与宽高比解析计算，窄屏自动后退；雾距离随取景等比缩放，避免竖屏时建筑被雾冲淡。

## 运行方式

需要 Node.js（建议 22 LTS）。

```bash
npm install
npm run dev -- --host 0.0.0.0
```

打开终端实际输出的 `Local` 地址（默认 `http://localhost:5173/`）。

生产构建：

```bash
npm run build      # 产物输出到 dist/
npm run preview -- --host 0.0.0.0
```
